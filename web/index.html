Easy setup for aruaru-llm / aruaru-llmの簡単セットアップ

Honest disclosure: There is no one-click installer yet — this Phase 0 script still requires Git and the Rust toolchain (rustup.rs) to be installed first, and it builds from source. A prebuilt-binary download (via open-easy-web) is planned for later. Also: aruaru-llm has real, non-optional cross-repo path dependencies deeper than expected — it needs open-cuda, RPoem, open-web-server, and RS-SmartTCP cloned as sibling folders, not just itself. This "easy setup" clones all five; it's not actually a lightweight single-repo build.
正直な開示: まだワンクリック・インストーラーはありません。このPhase 0 スクリプトはGitとRustツールチェーン(rustup.rs) が事前に必要で、ソースからビルドします。実行ファイル配布(open-easy-web経由)は今後の予定です。 また、aruaru-llmは想定以上に深いクロスリポジトリの 必須依存(オプションではない)を持っており、open-cuda・ RPoem・open-web-server・ RS-SmartTCPを同じ階層にクローンする必要があります。 この「簡単セットアップ」は5リポジトリすべてをクローンします—— 実際には単一リポジトリの軽量ビルドではありません。

Windows (PowerShell)

Run this in a normal PowerShell window (not as Administrator, not in C:\Windows\System32 — that folder is protected and will fail with "Permission denied"). It clones into your user folder.
通常のPowerShell(管理者権限なし、C:\Windows\System32では 「Permission denied」になります)で実行してください。ユーザー フォルダ内にクローンされます。 

cd $env:USERPROFILE
git clone https://github.com/aon-co-jp/open-cuda
git clone https://github.com/aon-co-jp/RS-SmartTCP
git clone https://github.com/aon-co-jp/open-web-server
git clone https://github.com/aon-co-jp/RPoem
git clone https://github.com/aon-co-jp/aruaru-llm
cd aruaru-llm
cargo run --release

Linux / macOS (bash)

cd ~
git clone https://github.com/aon-co-jp/open-cuda
git clone https://github.com/aon-co-jp/RS-SmartTCP
git clone https://github.com/aon-co-jp/open-web-server
git clone https://github.com/aon-co-jp/RPoem
git clone https://github.com/aon-co-jp/aruaru-llm
cd aruaru-llm
cargo run --release

Once it's running, this page will show aruaru-llm: connected at the bottom automatically (checked via /healthz).
起動すると、このページ下部の表示が自動でaruaru-llm: connected になります(/healthzで確認)。

Google Search Setup / Google検索の設定

Honest disclosure: This uses the Google Custom Search JSON API. You need your own API key and Search Engine ID (cx) — this app does not include or acquire one for you, and never sends it anywhere except your own local aruaru-llm server (kept in memory only, never written to disk).

正直な開示: Google Custom Search JSON APIを使用します。 APIキーと検索エンジンID(cx)はご自身で取得してください——このアプリは キーを同梱・取得代行しません。入力した値はお使いのPC上のaruaru-llm サーバーへのみ送信され、メモリ上にのみ保持されます(ディスクへの保存は 行いません)。

  1. Programmable Search Engine — create a search engine (site: example.com then enable "Search the entire web"), copy the Search engine ID (cx).
    検索エンジンを作成し(サイトにexample.com等を入れてから 「全ウェブを検索」をON)、検索エンジンID(cx)をコピー。
  2. Google Cloud Console — enable "Custom Search API", then create an API key under "APIs & Services → Credentials" (free up to 100 queries/day, no billing required for the free tier).
    「Custom Search API」を有効化し、「認証情報」からAPIキーを作成 (1日100件まで無料、無料枠の範囲では課金設定不要)。

You can change the level and reply language above at any time, before or during the conversation. / レベル・応答言語はいつでも(会話の前でも途中でも)上のメニューから変更できます。

Hi! I'm your English trainer. Choose your level above, then type or press the mic to start! / レベルを選んで、話すか入力してね!
Honest disclosure: AI responses are generated by a base GPT-2 language model (via aruaru-llm's /v1/generate) with no dialogue fine-tuning. Response quality and level-matching are not guaranteed. Voice input/output uses the browser's built-in Web Speech API (not all browsers support it). This is a Phase 0 prototype, not a production tutor.

正直な開示: AIの応答は、対話用のファインチューニングを 受けていない素のGPT-2言語モデル(aruaru-llmの /v1/generate経由)が生成しています。応答の品質・ 指定レベルへの適合は保証されません。声の入出力はブラウザ標準の Web Speech API(対応ブラウザのみ)を使用します。これはPhase 0の 試作品であり、本番運用レベルの講師ではありません。
