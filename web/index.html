Google Search Setup / Google検索の設定

Honest disclosure: This uses the Google Custom Search JSON API. You need your own API key and Search Engine ID (cx) — this app does not include or acquire one for you, and never sends it anywhere except your own local aruaru-llm server (kept in memory only, never written to disk).

正直な開示: Google Custom Search JSON APIを使用します。 APIキーと検索エンジンID(cx)はご自身で取得してください——このアプリは キーを同梱・取得代行しません。入力した値はお使いのPC上のaruaru-llm サーバーへのみ送信され、メモリ上にのみ保持されます(ディスクへの保存は 行いません)。

  1. Programmable Search Engine — create a search engine (site: example.com then enable "Search the entire web"), copy the Search engine ID (cx).
    検索エンジンを作成し(サイトにexample.com等を入れてから 「全ウェブを検索」をON)、検索エンジンID(cx)をコピー。
  2. Google Cloud Console — enable "Custom Search API", then create an API key under "APIs & Services → Credentials" (free up to 100 queries/day, no billing required for the free tier).
    「Custom Search API」を有効化し、「認証情報」からAPIキーを作成 (1日100件まで無料、無料枠の範囲では課金設定不要)。

Recommend an LLM / おすすめLLM

Honest disclosure: This reads your GPU VRAM/CPU/system-memory/NPU detection results from aruaru-llm (GET /v1/recommend) and picks a size heuristically (VRAM < 2GB → 124M, 2-4GB → 355M, 4-8GB → 774M, 8GB+ → 1.5B). It is a rough parameter-count-vs-VRAM estimate, not a precise benchmark.

正直な開示: aruaru-llmの GET /v1/recommendが返すGPU VRAM/CPU/システムメモリ/NPU検出結果を元に、 簡易ヒューリスティック(VRAM 2GB未満→124M、2-4GB→355M、4-8GB→774M、8GB以上→1.5B)で サイズを選びます。パラメータ数とVRAM容量の大まかな見積もりであり、精密な ベンチマークではありません。

Setup aruaru-db & PostgreSQL / aruaru-db・PostgreSQLのセットアップ

Setting up open-easy-web + PostgreSQL + aruaru-db will let this app (and others) process large amounts of information faster in the future.

open-easy-webとPostgreSQLとaruaru-dbをセットアップして頂きますと、 将来大量の情報をより高速で処理する事も可能になる予定です。

Honest disclosure: This is shared infrastructure — install it once per machine/server (not once per app). It is managed by open-easy-web's multi-tenant ("shadow clone") design, so once it's running, other apps/domains on the same machine can reuse it without reinstalling. This app (open-english) works fine without it (the geography/travel content falls back to a built-in dataset).

正直な開示: これは共有インフラです——マシン/サーバーごとに 一度だけセットアップすれば十分です(アプリごとに毎回インストールする ものではありません)。open-easy-webの分身の術(マルチテナント)構成で管理されるため、 一度動かせば同じマシン上の他のアプリ/ドメインも再インストール不要で使い回せます。 本アプリ(open-english)自体は無くても動作します(地理・観光の内容は 組み込みデータへ自動的にフォールバックします)。

1. PostgreSQL

postgresql.org/download から、お使いのOS向けのインストーラーをダウンロード・実行 してください(Windows/Linux/macOSいずれも公式インストーラーあり)。

2. aruaru-db

✅ Recommended / 推奨: git不要のビルド済みダウンロード。展開したフォルダで install.ps1(Windows)/install.sh(Linux/macOS、 既にダウンロード済みなので中のgit clone行は不要です)を実行 するだけです。

⬇ Windows (.zip) ⬇ Linux (.tar.gz)

Advanced / 上級者向け(ソースから):

Windows (PowerShell)

cd $env:USERPROFILE
git clone https://github.com/aon-co-jp/aruaru-db
cd aruaru-db
./install.ps1

Linux / macOS (bash)

cd ~
git clone https://github.com/aon-co-jp/aruaru-db
cd aruaru-db
./install.sh

セットアップ後、open-easy-webから他のアプリ/ドメインを登録すると 同じPostgreSQL/aruaru-dbインスタンスをそのまま共有できます(詳細は open-easy-web参照)。
